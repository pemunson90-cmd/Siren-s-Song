# Actual local v7 browser observation

This supplements the source audit with an actual run of the immutable [original v7](../../../../reference/original-prototype/sirens_song_prototype_v7.html). It is **not shipped-game reference footage**, a blind comparison or a production quality verdict. Barotrauma / Door Kickers / Mark of the Ninja motion comparison remains pending; previous external-media restrictions are unchanged.

Existing Chromium 154.0.8037.57, Python Playwright and `/usr/bin/ffmpeg` were used without installation. The local HTML was loaded unchanged through `page.set_content`; Chromium policy disallowed `file://` navigation. External font requests were aborted, so the visible font is the built-in fallback. Playwright's missing bundled ffmpeg path was supplied by a temporary symlink to the already-installed system ffmpeg. No external media, game state edits, simulation acceleration or source modifications were used. The browser recording has no captured audio.

- [14-second idle clip](idle.mp4): full recording seconds 1–15; no input after DIVE. Actual normal player view hides distant enemies, so motion outside sensors is **not visually demonstrated** by this clip.
- [16-second ping/response clip](ping-response.mp4): full recording seconds 17.5–33.5, after one ordinary PING click. A patroller becomes visible near Quietus, closes in, and the player loses. No evasion input was issued. This establishes an actual audible-stimulus encounter in this run, not that losing is inevitable or desirable.
- [Sampled sequence](contact-sheet.png): frames every four seconds from the full recording, inspected directly along with the final loss frame. This is a sampled visual inspection, not a claim that every video frame was watched.
- [Read-only runtime observations](runtime.json): sampled once per host second through the existing JavaScript state. This is a separate diagnostic channel and includes offscreen information the player cannot see. No page errors were reported.

At idle start, the patrollers are approximately `(599.81,1115.98)` and `(599.83,1332.05)`. At 16 seconds they are `(223.10,1080.07)` and `(469.56,1403.85)`, both having advanced waypoint index 0→1. Sentinel `(888,324)` and hunter `(72,180)` remain at home. Immediately after PING, the second patroller has investigation time 6.48 seconds. At the final sample it has reached approximately `(599.87,1655.74)`, sees the pilot, and the screen is `lost`. Station-role stimulus/pursuit was not exercised in this bounded original-v7 capture.

Source SHA-256, exact browser version and times are retained in `runtime.json`. The capture driver is retained for inspection; its `/tmp` output and repository input path reflect this environment rather than portable infrastructure. Source-preserved originals remain untouched. Clip trimming uses wall-clock recording offsets; simulation timestamps come from the separate sampled runtime channel and are not claimed as frame-perfect alignment. The full scratch recording is `/tmp/sirens-v7-browser/v7-full.webm`; only small review excerpts are retained in Git. Requested Sol 6.1, actual backend/cost telemetry unknown; no nested agents.
