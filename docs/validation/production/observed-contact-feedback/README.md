## Bounded design and tradeoffs

The probe's long HUNTER/INVESTIGATE and LAST SEEN/ECHO labels collided with ARCHIVE NODE and lost actor identity. Chosen: short, screen-sized S# world tags plus a readable cached-observation strip where the existing fresh-beam strip already lived. Fresh rows show observed role/mode; stale rows show last-observed role and explicit LAST SEEN age, never a remembered mode presented as current. Fresh beams with a live own target and clear current line of sight sort first, retaining their target and countdown. Remaining rows preserve cached observation order. World tags share the row's same identity and disappear with expired observation memory. No hidden actor total or Siren array data is read.

Rejected alternatives: enlarge or spread long world labels (more map collisions); add a modal/tutorial paragraph (unproven clutter); assign new identities at each reacquisition (loses echo continuity); infer “heard the decoy”/“returned safely” from hidden AI (unfair certainty). Actual v7 was reread: role-specific shape/label and “? TYPE” investigation marking are useful precedent, but it has no production persistent observed ID/readout. Its sight-before-lure branch remains authoritative reference; the actual new losing counterexample confirms the bounded production behavior. No v7 radius, duration or direct-motion constants are copied.

The strip uses more chart overlay when nonlocking contacts exist, trading that occupancy for legible identity and freed objective labels. It does not shrink the chart or change controls. Urgent observed locks stay first; short tags are drawn beneath instrument panels so panning cannot print them over instrument text. Two contacts close together may still have nearby short tags, but the readout retains their distinct identity/role/age. Future crowded encounters beyond today's tested three-contact layout may need further work; this is not a whole UI quality claim.

`contact_feedback.gd` accepts cached contacts, simulation elapsed time and own-unit data, plus the existing line-clear predicate. It returns fresh value dictionaries. It never reads hidden Sirens. Freshness remains the existing<0.3s convention, cached observation expiry>20s; pause/menu/outcome clocks and serialized restore reuse existing state. The simulation delta is only the launch string. Sensing, AI, physics, resources, durations, route controls and save schema are unchanged. No “successfully diverted” or expiry-means-safe text is added.
