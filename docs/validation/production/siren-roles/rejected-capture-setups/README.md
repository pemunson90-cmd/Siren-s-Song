# Rejected capture setups

Retained as evidence of setup mistakes, not the final player-view clips. These 1680×720 full screenshots are valid actual framebuffers, but Godot MovieMaker emitted 1280×720 frames and cropped the right edge; final clips use a matching 1280×720 window/encoder. The first idle-patrol setup also used RECON, whose acoustic uplink provokes an enemy, so it is not unprovoked evidence. The first passive-patrol setup started too early in the circuit to expose much visible circulation; the revised setup adds a documented ordinary simulation pre-roll. No game mechanics were changed to improve the captures.

The failed-lure and failed-return-preroll files are actual losing choices, not framing failures. A decoy drawn too close to a passive observer brings a hunter into beam range; the late600,600 observer is later reached by another patrol hearing the same lure. These are retained causal risks, not suppressed actor behavior.
