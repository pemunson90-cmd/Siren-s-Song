# Daily digest template (what reaches Pat's phone)

One message a day at a fixed time (proposal 20:00 ET), 12 lines max, plain language, numbers only where they change what he would decide. A push notification goes out only when the question at the end blocks work. Generated by the orchestrator from STATE.md, the nightly `metrics.json` and `queue.json`; a Haiku helper may draft it, the orchestrator sends it.

```
Siren's Song, <date>
Merged: <n> items (<one phrase each, player-facing>)
Nightly: <GREEN|RED>. Finishable by hand: <x/y ops>. Control mix: <n%> one-press (release policy must read 0%).
Biggest weakness now: <one line, from the latest critic or metric>
Working on: <item title> (<phase>), next: <item title>
Blocked: <none | one line with the reason>
Decisions you can revert: D<nn> <five words>, D<nn> <five words>
Question (yes/no, recommendation first): <one line, or "none today">
```

## Milestone card (replaces the digest on a milestone day)

```
Milestone <tag>, <date>
[one screenshot of the game played as designed]
Finishable by hand: <x/y>. Mix: <n%>. Hull lost per op (median): <n>. Frame time proxy: <ms>. Voice drops per dense event: <n>. Ending reached by critics: <yes/no>.
Top 3 weaknesses: 1 <line> 2 <line> 3 <line>
Reference pairs: won <a>, held <b>, lost <c> (<which pieces lost>)
Workflow review: <one fix we are making to how we work>
Question: <one line>
```

## Rules

- Never ask two questions. Never ask him to click, merge or run anything.
- A qualifier in his answer ("for now") is recorded verbatim in RULINGS.md as provisional.
- If there is nothing to report, send the digest anyway with "quiet day" so he knows the loop is alive.
