# Fleet-matters fix patterns (Claude S5, 28 Oct 2026; AI-DESIGNED, Pat ratifies)

Purpose: when 093 classifies an op as WAYPOINT or THIN, Claude writes a fix handoff using patterns from this page. That way, fixing an op doesn't start from a blank page.

Pat's rule (28 Oct): a bare launch finishing an op is a **skill feat**: possible for a skilled player, demanding, with worse results. Planning, drones, tools and progression must change the outcome. The game must not feel like a walking simulator in a submarine.

## Hard limits (every pattern)
- No change to Siren senses, lock timing (4 s interruptible), beam lethality, collision, damage or hull rules, photography design, art direction or ending conditions beyond Pat's rulings. Existing roles keep their behavior. Patterns change **where things are, what the job asks and what the result pays**.
- A required route is never gated behind a finite tool or a drone that can be lost. The bare finish stays possible.
- Story text stays 1 to 2 line placeholders. No em dashes.

## Patterns (pick 1 to 3 per op)
1. **Outcome tiers.** The bare minimum completes the op; fuller results need the fleet. Examples: people rescued (more pods than Quietus can carry in one trip within oxygen), photo grade (the best viewpoint is exposed and suits a drone), recovered cargo, pay, ledger and ending lines. Tie each tier to an existing fact or reward; never add a new currency.
2. **Two places at once.** Two pieces of work that pay off when done at the same time or in a short window: a drone holds a station, door or shore power while Quietus passes; one craft listens while another works. Warning Chain's shore power is the model.
3. **Information has to be earned.** The objective or the safe gap is unknown at launch. Scouting with a drone, a Sonobuoy's bearings, a Survey uplink or the earned chart (089) finds it safely. A bare sub finds it by exposing itself.
4. **Timing gaps that tools widen.** Place existing guards so the bare route needs a precise, tight timing window. Decoy, Disrupt, Silt screen or Torpedo widen the window at a cost (noise, Hunt, stock). This changes positions and patrol points only, never senses.
5. **Endurance pressure.** Oxygen or drone endurance is set so a careless bare route runs short, while a planned route (relay, shortcut module, parallel work) has margin. Endurance values are mission data, not protected rules.
6. **Progression shortcuts.** A module or alien artifact opens a quieter or shorter path (065/066 style). Without it, a longer and louder path. Ops after an artifact should use it.
7. **Losses that matter.** Drone loss, wear and spent tools carry forward through the economy (054) and Ironman, so caution and planning pay over a campaign, not just one op.
8. **Survival pressure.** On SURVIVAL only: tighter endurance, fewer free resupplies, harsher ledger outcomes for bare minimum finishes. Same senses and rules. Numbers are provisional (Pat ruling 5).

## Per-op fix handoff checklist
- The op, its 093 class and the cause in one line.
- Chosen patterns and the exact data seams (mission builder, objectives, endurance, guard placement, rewards).
- Success measure: rerun the 093 bare and equipped pair. The op must now be EARNED. The bare run must show real risk (at least one lock warning, a Hunt peak above the low band, or under 25 percent oxygen margin) and still finish on STANDARD.
- Teaching: one briefing line names the equipped option (067 owns the wording pass).
- Batch 3 to 5 ops per handoff by region, so they don't collide in shared files.
