For each branch: create tag `archive/branch/<name>` at the tip, push the tag to `origin`, then remove the branch ref. A tag holds every commit of the branch, so the history stays reachable and a branch can be recreated from its tag at any time.

Commands for Pat (or a later session with his approval), run from the repository root. The first three lines refresh the ledger, because branches change class as they age and as pull requests open and close:

```
git fetch --all
gh pr list --state all --limit 1000 --json number,state,headRefName,baseRefName > prs.json
python scripts/repo/branch_ledger.py --prs prs.json > .fable/BRANCH_LEDGER.md
python scripts/repo/archive_branches.py --execute --approved-by-pat
python scripts/repo/archive_branches.py --remove-branches --approved-by-pat
```

The `--execute` command only adds tags. The `--remove-branches` command removes a branch only where the remote already has its archive tag at the same commit.
