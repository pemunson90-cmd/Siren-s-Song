# Siren's Song

Original Android-first 2D tactical submarine-stealth and reconnaissance game. One pilot commands USS Quietus and two drones through alien industrial water, acoustic exposure, incomplete information and superior Siren threats.

**Active production:** [`gauntlet/production`](https://github.com/pemunson90-cmd/Siren-s-Song/tree/gauntlet/production). Godot 4.6.3 / GDScript / Compatibility is the established engine. The actual integrated version, ownership, open defects, Android evidence and next task live in [CONTINUATION.md](docs/CONTINUATION.md) and [WORKBENCH.md](docs/WORKBENCH.md). Don't duplicate their changing status here.

Start with [AGENTS.md](AGENTS.md), [current game specification](docs/CURRENT_GAME_SPEC.md), [source authority](docs/SOURCE_AUTHORITY.md), [v7 parity ledger](docs/V7_TO_GODOT_PARITY.md), and [design bible](design/SIRENS_SONG_DESIGN_BIBLE_GAUNTLET_V1.md). Accepted visual direction is in the [concept selection ledger](references/package/SIRENS_SONG_CONCEPT_SELECTION_LEDGER.md) and [visual package handoff](references/package/START_HERE.md).

The Gauntlet continually improves the whole playable game. **The user alone can terminate the program.** Completed tasks trigger policy refresh, handoff staleness repair and the next delegated work while usage and execution remain available. Every proposed integration is reviewed on its own branch and reconciled against the current production tip; `main` is the protected accepted-promotion branch.
